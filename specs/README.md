# Specifications

Executable-shaped descriptions of what catalog artifacts do. They are written in Gherkin so that a behaviour has one
statement a reader, a reviewer, and a test can all point at.

A scenario here is a claim about the catalog's own behaviour, not a test of an adopting repository. Adopters may run
these against their own implementations; nothing requires them to.
