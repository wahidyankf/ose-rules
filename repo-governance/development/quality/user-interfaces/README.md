# User Interfaces Standards

User interface standards. They answer how an interface stays accessible, visually consistent, and sound when it ships.

## Directory Map

- [Accessibility](accessibility.md) — contrast, focus, keyboard, forms, targets, motion, roles, release check
- [Accessibility Modules](accessibility/README.md) — focus, forms and targets, content and motion, roles, release
- [Design Tokens](design-tokens.md) — tokens as the single authority for visual values and themes
- [Design Tokens Modules](design-tokens/README.md) — notation, value format, and dark activation choices
- [User-Facing Delivery Hardening](user-facing-delivery-hardening.md) — plan authoring, deployment-configuration sweep,
  archival sign-off, and near-end retest rules that keep design and behaviour defects from passing green gates
- [User-Facing Delivery Hardening Modules](user-facing-delivery-hardening/README.md) — authoring a user-facing plan, and
  executing, signing off, retesting, and archiving it
- [Utility-First Styling](utility-first-styling.md) — utility classes in markup, components for repeated combinations,
  no importance overrides or inline styles, canonical class order, and mobile-first layout
