# Enforcement Disposition

Each obligation is **unenforced by decision**; review checks the observations in
[002 Verification Observations](002-verification-observations.md). No mechanical check proves bytes were never opened, a
command was entered by the user personally, free text holds no secret, a lock preceded a pause, a pipeline is adequate,
or a review actually read.
