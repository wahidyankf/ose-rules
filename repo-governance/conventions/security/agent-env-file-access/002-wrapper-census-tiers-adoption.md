# Wrapper Census Tiers Adoption Observations

- Conforming wrapper: a delivery lists one tracked wrapper path per secret-bearing surface with no second
  secret-touching path.
- Violating wrapper: a surface lands with no tracked wrapper or with a second secret-touching path.
- Conforming matrix: a delivery records one closed executor split with consumed-only-to-consumer allowed and any print
  to transcript refused.
- Violating matrix: a move prints to transcript, log, or result document, or a human-only move runs outside the operator
  terminal.
- Conforming census: the census holds one row per surface recording location never value; unlisted stays reported as
  unlisted.
- Violating census: a surface lacks its row or a row carries a value.
- Conforming tiers: the adopter records canonical versus non-canonical names with one template per consumer and
  tier-free keys; no tier filename stands as universal.
- Violating tiers: a non-canonical name is referenced as a live value source or a tier filename is presented as
  universal.
- Conforming adoption: a delivery review cites the adoption rule with census row, wrapper/matrix, tier-vocab note, and
  harness routing landing in the same delivery unit.
- Violating adoption: a surface lands without all four in the same delivery unit.
